# 맵 파일 형식

맵 파일은 `SandTag.registerMap({ ... })` 한 번을 호출하는 자바스크립트 파일이에요.
`canyon.js`가 짧은 예시라서 복사해서 시작하기 좋아요.

## 좌표

- **칸 좌표 (c, r):** 맵은 격자예요. 한 칸은 4m이고, c는 가로(왼쪽→오른쪽), r은 세로(위=북쪽→아래=남쪽)예요.
- **월드 좌표 (x, z):** 미터 단위예요. x = c × 4, z = r × 4. 예를 들어 칸 (3, 5)의 가운데는 x=14, z=22예요.
- 사각형은 `[c0, r0, c1, r1]` 형태이고 끝 값(c1, r1)은 포함하지 않아요. `[2,5,6,8]`은 c=2~5, r=5~7이에요.

## 항목

| 항목 | 단위 | 설명 |
|---|---|---|
| `id` | | 영문 이름. maps/index.js의 id와 같아야 해요 |
| `name`, `desc` | | 메뉴에 보이는 이름과 설명 |
| `size` | 칸 | `[가로, 세로]` |
| `floor` | 칸 사각형 | 걸을 수 있는 바닥. 나머지는 모두 벽(바위)이 돼요 |
| `holes` | 칸 사각형 | floor 안에서 다시 벽으로 만들 곳 |
| `buildingWalls` | 칸 사각형 | 이 안의 벽은 바위 대신 흰 건물 벽으로 그려요 |
| `lowBuildings` | 칸 | 옥상에 올라갈 수 있는 2층 건물. `{c0,r0,c1,r1,h,name}`, h는 높이(m, 4~4.5 권장) |
| `ramps` | 미터 | 경사로 `{x0,x1,z0,z1,hi,h,base}`. hi는 높은 쪽 변(`'x0'`,`'x1'`,`'z0'`,`'z1'`). 낮은 쪽 높이는 base(없으면 0). 2층 옥상에서 3층으로 오르는 계단은 base:4.5, h:9 |
| `boxes` | 미터 | 단단한 상자 `{x0,x1,z0,z1,y0,y1,k}`. k 종류는 아래 표 |
| `planters` | 미터 | 화분 `[x, z, 가로, 세로, 나무('cone'/'round'/null), 바닥 높이]`. 나무가 있으면 줄기에 부딪혀요. 옥상에 두려면 마지막 값에 옥상 높이 |
| `crates` | 미터 | 상자 `[x, z, 높이]` (2×2m). 높이 1은 점프로 올라가요 |
| `zones` | 칸 | 노란 구역 `{n,c0,r0,c1,r1}` 여러 개. 도망자가 들어가면 술래에게 보여요. orbs.zones에 구역마다 후보 목록을 같은 순서로 넣어요 |
| `floorPaint` | 칸 | 바닥 색칠(다리 무늬 등) `{c0,r0,c1,r1,color}` |
| `door` | 칸 | 탈출문 `{c0,r0,c1,name}`. 한 줄짜리이고, 바로 아래 칸(r0+1)이 바닥이어야 해요 |
| `portals` | 미터 | 텔레포트 문 0개 또는 2개 `{x,z,yaw,ex,ez,eyaw}`. ex/ez는 나오는 위치 |
| `spawns` | 미터 | `{runner:{x,z,yaw}, seeker:{x,z,yaw}}`. yaw 0은 북쪽, Math.PI는 남쪽 |
| `orbs` | 칸 | 구슬 후보. `zones`(구역별 목록), `up`(옥상·다리 위), `ground`(바닥). 합쳐서 15개 이상 |
| `decor` | 미터 | 장식(충돌 없음) `{t:'tower',x,z,h,w}`, `{t:'dish',x,z,r,rot}`, `{t:'warehouse',x,z}`, `{t:'tree',x,z,y,kind,s}`, `{t:'rock',x,z,y,s}`, `{t:'sail',x,z,rot}` |
| `style` | | 선택. `'neo'`면 흰 건물, 파란 유리, 잔디 옥상, 흰 계단의 미래 도시 느낌으로 그려요 (네오 플라자) |
| `palette` | | 선택. `{sand:[r,g,b], rock:['#색',...]}` |

### boxes 종류 (k)

| k | 쓰임 |
|---|---|
| `bridge` | 구름다리 바닥. y0~y1을 4.1~4.5처럼 얇게 두면 아래로 지나갈 수 있어요 |
| `rail` | 다리 난간. 다리 위(y0=다리 높이)에 얇게 |
| `deck` | 기둥 위 2층 발판 |
| `pillar` | 기둥 |
| `slide` | 슬라이딩 통로. y0=0.95, y1=3.4로 두면 도망자가 슬라이딩으로만 지나가요. 술래에게는 벽이에요 |
| `crate` | 상자 (보통은 `crates` 목록이 더 편해요) |

## 맵 검사

맵을 불러올 때 자동으로 검사해요. 문제가 있으면 메뉴에 경고가 뜨고, 콘솔에 자세히 나와요.

- 스폰 위치가 바닥인지
- 도망자가 탈출문과 술래 스폰까지 갈 수 있는지
- 구슬 후보마다 도망자와 술래가 모두 갈 수 있는지
- 텔레포트 출구가 막혀 있지 않은지
- 구슬 후보가 15개 이상인지

슬라이딩 통로만으로 이어진 곳은 술래가 갈 수 없으니, 그런 곳에 구슬을 두면 경고가 떠요.
