# 모래 요새 술래잡기

1인칭 술래잡기 웹 게임. 술래잡기와 1:1 총싸움 두 모드를 AI 상대로, 또는 방 코드로 친구와 온라인으로 할 수 있어요.

## 폴더 구조

```
index.html        화면 뼈대와 스크립트 불러오는 순서
css/style.css     화면 디자인
js/
  version.js      버전 번호와 업데이트 내역  ← 업데이트할 때 여기를 고쳐요
  core.js         맵 데이터 해석, 충돌, 점프·경사로 물리, AI 길찾기 그래프, 맵 검사
  maps.js         maps 폴더에서 맵 파일을 불러오는 로더
  prefs.js        저장되는 설정, 효과음
  render.js       렌더러, 그래픽 품질, 하늘·반사·그림자·빛 번짐, 질감(노멀맵) 생성
  world.js        현재 맵을 3D로 짓기 (바닥, 벽, 건물, 계단, 다리, 나무, 잔디, 먼 풍경)
  actors.js       갑옷 캐릭터 모델, 구슬
  minimap.js      미니맵
  game.js         게임 상태, 조작, 슬라이딩·점프·텔레포트·레이더, 판 진행
  combat.js       총, 체력, 피해, 1:1 총싸움 라운드
  ai.js           AI 술래
  relay.js        중계 서버(MQTT) 연결
  net.js          온라인 방, 대기실, 게임 동기화
  hud.js          화면 표시
  main.js         메인 루프, 메뉴, 버전 표시, 시작 순서
maps/
  index.js        맵 목록
  fortress.js     모래 요새
  canyon.js       협곡 시장
  neoplaza.js     네오 플라자 (3층, 미래 도시 스타일)
  README.md       맵 파일 형식 설명
```

js 파일은 index.html에 적힌 순서대로 불러와요. 뒤 파일이 앞 파일의 함수를 쓰니까 순서를 바꾸지 마세요.

## 실행하기

- **웹에 올리기:** 이 폴더 전체(index.html이 들어 있는 폴더)를 Netlify Drop 등에 그대로 끌어다 놓으면 돼요.
- **내 컴퓨터에서:** index.html을 더블클릭해도 실행돼요. 다만 업데이트 확인 기능은 웹 주소로 열었을 때만 작동해요.
- 로컬 서버로 열고 싶으면 이 폴더에서 `python -m http.server`를 실행하고 http://localhost:8000 으로 들어가요.

## 맵 추가하기

1. `maps/canyon.js`를 복사해서 `maps/새이름.js`를 만들고, 안의 `id`를 새 이름으로 바꿔요.
2. `maps/index.js` 목록에 한 줄 추가해요.
3. 게임 메뉴에서 새 맵을 골라서 확인해요. 맵에 문제가 있으면 메뉴 아래에 "맵 검사" 경고가 뜨고, 자세한 내용은 브라우저 개발자 도구 콘솔에 나와요.

맵 파일 형식은 `maps/README.md`에 있어요.

## 업데이트 올리기

1. `js/version.js`의 `GAME_VERSION`을 올려요 (예: 3.1.0 → 3.2.0).
2. `GAME_CHANGES` 맨 위에 바뀐 내용을 한 줄 추가해요.
3. 폴더를 다시 올려요.

이미 게임을 켜 둔 사람의 화면 오른쪽 아래에는 "새 버전 있음"이 떠요. 누르면 새로고침돼요.
온라인 대결은 두 사람의 버전이 다르면 시작되지 않고, 새로고침하라는 안내가 나와요.

## 그래픽

- 메뉴 > 게임 설정 > 그래픽 품질에서 높음 / 보통 / 낮음을 고를 수 있어요. 휴대폰은 처음에 '보통'으로 시작해요.
  - 높음: 실시간 그림자(고해상도), 빛 번짐(블룸), 계단 현상 완화, 반사, 잔디
  - 보통: 그림자(중간 해상도), 반사, 잔디 조금, 빛 번짐 없음
  - 낮음: 그림자와 반사 없이 가볍게
- 효과용 추가 파일(three.js r128 add-on)은 인터넷에서 불러와요. 못 불러오면 그 효과만 꺼지고 게임은 그대로 돼요.
