# CODE-NAME — 1인칭 술래잡기 & 배틀 (웹) v7.4.0

설치 없이 브라우저에서 돌아가는 1인칭 게임이에요. PC(키보드·마우스)와 휴대폰(터치) 모두 돼요. 친구와는 **방 코드**만으로 같이 할 수 있어요(계정 없음).

## GitHub Pages에 올리기
이 폴더 **안의 내용물**(index.html이 있는 곳)이 저장소 맨 위에 오도록 올려요.

1. GitHub에서 새 저장소를 만들어요(Public).
2. 파일 올리기 — 둘 중 하나:
   - **GitHub Desktop (가장 쉬움):** 저장소를 내 컴퓨터로 Clone → 이 폴더 안의 내용물을 전부 그 폴더에 복사 → Commit → Push.
   - **웹에서 끌어다 놓기:** 파일이 215개인데 웹 업로드는 한 번에 100개까지라서 4번에 나눠요. 폴더를 끌어다 놓으면 그 안의 구조는 그대로 올라가요.
     1. 저장소 첫 화면에서 *Add file → Upload files* → `index.html`, `README.md`, `CREDITS.md`, `css`, `js`, `lib`, `maps` 를 끌어다 놓고 Commit.
     2. *Add file → Create new file* → 이름 칸에 `assets/.keep` 입력 → Commit. (빈 `assets` 폴더 만들기)
     3. 저장소에서 `assets` 폴더로 들어가서 *Add file → Upload files* → `assets` 안의 `fonts`, `hdri`, `ui`, `models` 를 끌어다 놓고 Commit.
     4. 같은 곳(`assets`)에서 한 번 더 → `sfx` 를 올려 Commit, 마지막으로 `tex` 를 올려 Commit.
3. 저장소 *Settings → Pages → Build and deployment*에서 Source를 **Deploy from a branch**, 브랜치를 **main / (root)** 로 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열려요.

`.nojekyll` 파일(숨김 파일)은 GitHub이 파일을 손대지 않고 그대로 보여 주게 해요. 빠져도 게임은 돌아가요.

## 내 컴퓨터에서 실행
ES 모듈과 3D 에셋을 불러오기 때문에 **웹 서버로 열어야** 해요(index.html을 더블클릭하면 안 돼요).
폴더에서 `python -m http.server 8000` → 브라우저에서 `http://localhost:8000`

## 게임
- **술래잡기** — 도망자는 구슬을 모두 모아 탈출문으로, 술래는 앞쪽 60°만 봐요. 노란 구역에선 도망자가 드러나요. 잡힌 동료는 감옥에서 구출할 수 있어요. 술래 수는 7명까지 1명, 8~14명 2명, 15명부터 3명.
- **배틀** — 총 32종 + 칼, 투척 10종, 특수 5종, 퍼크 17종. 총마다 조준경·총구·총열·손잡이·개머리판·탄창을 바꿀 수 있어요. 모드 11개: 팀 데스매치, 개인전, 1:1, 건게임, 킬 컨펌드, 깃발 뺏기, 하드포인트, 점령전, 수색과 파괴, 업로드, 파쿠르.
- **맵 4종** — 사막 요새, 네오 플라자, 네온 시티, 버려진 공장. 모두 들어갈 수 있는 다층 건물이 있어요.
- **봇** — 쉬움(초보) / 보통(평균) / 어려움(고수).

## 온라인
방장이 방을 만들면 5글자 코드가 나와요. 친구는 코드를 넣거나 **방 찾기**에서 골라 들어와요. 공개 MQTT 중계 서버(EMQX/HiveMQ/Mosquitto, 보안 연결 wss)로 메시지를 주고받고, 방장이 규칙과 봇을 맡아요. 방장 외의 플레이어가 나가면 그 자리는 봇이 이어받아요. GitHub Pages(https)에서도 그대로 돼요.
