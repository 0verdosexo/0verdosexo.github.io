# CODE-NAME — 1인칭 술래잡기 & 배틀 (웹)

설치 없이 브라우저에서 돌아가는 1인칭 게임이에요. 친구와는 **방 코드**만으로 같이 할 수 있어요 (계정 없음).

## 실행
ES 모듈과 3D 에셋을 불러오기 때문에 **웹 서버로 열어야** 해요 (파일을 더블클릭하면 안 돼요).
- 가장 쉬운 방법: 이 폴더를 통째로 GitHub Pages / Netlify / Cloudflare Pages 에 올리기
- 내 컴퓨터에서: 폴더에서 `python -m http.server 8000` → 브라우저에서 `http://localhost:8000`

## 게임
- **술래잡기** — N명. 술래 수는 7명까지 1명, 8~14명 2명, 15명부터 3명. 도망자는 구슬을 모두 모아 탈출문으로, 술래는 앞쪽 60°만 봐요. 노란 구역에선 도망자가 드러나요. 잡힌 동료는 감옥에서 구출할 수 있어요.
- **배틀** — 총 129종(돌격소총·기관단총·기관총·산탄총·지정사수·저격총·권총·특수 화기), 투척 10종, 특수 5종, 퍼크 18종(2칸, 겹치기 가능). 모드 11개: 팀 데스매치, 개인전, 1:1, 건게임, 킬 컨펌드, 깃발 뺏기, 하드포인트, 점령전, 수색과 파괴, 업로드, 파쿠르.
- **무기고 로드아웃** — 메인 화면의 로드아웃은 걸어 다니는 3D 무기고예요(정비실 + 방 4개). 진열된 총·부품·장비를 집으면 바로 장착돼요.
- **맵 4종** — 모래 요새(재설계), 네오 플라자(재설계), 네온 시티(신규), 버려진 공장(신규). 모두 들어갈 수 있는 다층 건물이 있어요.

## 온라인
방장이 방을 만들면 5글자 코드가 나와요. 친구는 코드를 넣거나 **방 찾기**에서 골라 들어와요. 공개 MQTT 중계 서버(EMQX/HiveMQ/Mosquitto)로 메시지를 주고받고, 방장이 규칙과 봇을 맡아요.
방장 외의 플레이어가 나가면 그 자리는 봇이 이어받아요.
